## 3. K1 重定向工具链（自己产数据）

**GMR（推荐，ICRA 2026）**：https://github.com/YanjieZe/GMR
- 原生支持 `booster_k1`（22 DoF：颈2+臂2×4+腿2×6）与 `booster_t1`。
- 输入：AMASS(SMPL-X)、LAFAN1(BVH)、OMOMO、Nokov BVH、OptiTrack FBX 实时流。
- 安装：`conda create -n gmr python=3.10 && pip install -e .`；SMPL-X 模型放 `assets/body_models/`。
- 单段：`python scripts/bvh_to_robot.py --bvh_file X.bvh --robot booster_k1 --save_path out.pkl --format lafan1`
- 批量：`python scripts/bvh_to_robot_dataset.py --src_folder ... --tgt_folder ... --robot booster_k1`
- IK 基于 mink + MuJoCo；CPU 实时。

**流程建议**（对齐火神方法）：
1. ACCAD 下全向行走（MartialArtsWalksTurns 系列）→ GMR → K1 轨迹
2. CMU subject#10 踢足球 / 自采动捕 → GMR → K1 踢球轨迹
3. 检查支撑足接触与可行性（速度/加速度限幅、足底滑移）
4. 转 NPZ 供 booster_train(BeyondMimic) 或自研 AMP 判别器使用
