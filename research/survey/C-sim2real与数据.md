## C1. 本仓库现状

- **只能纯仿真**（AGENTS.md 授权限制：不连真机、不执行任何安装/服务/固件脚本）。
- 官方 K1.yaml 电机参数来自 B-Human **悬挂实验**（hanging-robot experiments）：K1 踝 roll 刚度 65→25、T1 髋 roll 250→200——这是官方做过的一轮 real-to-sim 标定，免费继承。
- sim2sim 门已通：120 s = 6000 次策略调用，与 TorchScript 最大误差 7.15e-7、与 ONNX 1.43e-6（inventory/06）。注意这验证的是**部署数值一致性**，不是物理保真度。
- 环境：训练在 bh-gym（Isaac Gym Preview 4）；sim2sim 用 isaacsim-gui venv（Python 3.12.13 / MuJoCo 3.8.0 / Torch 2.11.0 CPU）。磁盘余量 62 G——隐性约束。

## C2. Booster Lab：数据中心管线的教科书（arXiv 2606.27813）

清华+Booster 联合（与火神同体系，Penghui Chen 等）。管线四段：

1. **动作数据整备（motion curation）**：筛选、清洗、重定向参考动作；
2. **real-to-sim 模型适配**：
   - 实测 Booster T1 电机 **T-n（力矩-转速）特性曲线**，取曲线**膝点**作为仿真电机的速度限与力矩限；
   - 电枢惯量按 **J_arm = N²·J_m**（N=减速比，J_m=电机转子惯量）计入关节；
3. **AMP + RSI 强化学习**训练（与火神同款先验）；
4. **MuJoCo / Webots 双仿真交叉验证**后部署。

评测方法学亮点：用**极限环（limit cycle）**把仿真步态与真实步态在 walk 0.6 m/s 与 run 2.0 m/s 双工况下逐点对比——比单看指令追踪误差更能暴露「仿真会、真机不会」。T1 全程验证，**K1 已有初步跨平台验证**。

**可直接抄**：
- 真机授权后第一件事：T-n 曲线测量协议（吊架、渐增速、记录失速点）；
- 现在就做：检查 K1.yaml 的电机限值与官方悬挂参数是否一致；
- 双仿真交叉验证思想 → 本仓库已有 MuJoCo sim2sim 通道，天然满足。

## C3. ASAP：delta action 残差模型（arXiv 2502.01143，RSS 2025）

CMU+NVIDIA（LeCAR Lab），代码开源 LeCAR-Lab/ASAP（基于 HumanoidVerse）。

**两阶段**：
1. 预追踪策略在真机上回放，收集「仿真动作 vs 真实状态响应」数据，训练 **delta action 残差模型**补偿动力学失配；
2. 冻结残差模型，在修正后的仿真里微调/重训策略。

**效果**：sim-to-real 追踪误差最多降 52.7%（G1 等高动态动作）。
**局限（原文自述）**：依赖动捕参考；23 DoF 需 >400 episodes 数据；高动态动作有硬件损伤风险。

**本仓库判断**：残差模型属于「真机之后」的工具；优先级低于 Booster Lab 的 T-n 标定（先把手动参数标定做满，再上学习式残差）。

## C4. 执行器建模与经典标定谱系

| 方法 | 出处 | 适用 |
|---|---|---|
| 手工悬挂实验 | B-Human 官方（本仓库已继承） | 单关节刚度/阻尼快速标定 |
| T-n 膝点定限 | Booster Lab 2606.27813 | 电机工作区包络 |
| **UAN 统一执行器网络** | MIT CSAIL（RSC 论文） | 准直驱关节，用网络学执行器动力学，替代手工参数表 |
| delta action 残差 | ASAP 2502.01143 | 整体动力学失配的端到端补偿 |
| 域随机化覆盖残差 | 经典 DR（K1.yaml 已有 noise/randomization 表） | 无真机数据时的唯一手段 |

## C5. 物理感知的观测噪声：PAiD 的做法

PAiD（2602.05310）第三阶段「physics-aware sim2real」：用**真实球下落实验与滚动实验**标定仿真的接触动力学参数，并据此设计 physics-guided 观测噪声分布。

**纯仿真阶段就能做的预热**：设计好标定实验清单与数据格式（球下落视频→恢复系数；球滚动→摩擦；单摆腿→关节响应），授权一到即可执行。

## C6. 升级清单（按授权阶段排列）

**现在（纯仿真）**：
1. 核对 K1.yaml 电机限值 = 官方悬挂实验值；
2. 把随机化表显式当作「残差覆盖预算」管理（每个随机化维度注明对应哪类真机不确定性）；
3. 评测门加入 SONIC 式自动失败判据（躯干高度偏差 >0.25 m / 朝向 >1 rad 判失败并早停）；
4. 磁盘纪律：训练产物只留 manifest 指定的检查点语义（actor/warm-start/full/torchscript），其余定期归档。

**真机授权后（P3）**：
5. T-n 曲线测量 → 更新电机限值；
6. 球下落/滚动标定 → 更新接触参数与观测噪声；
7. 极限环双工况对比报告（walk 0.6 / run 2.0）；
8. 差距仍显著 → 上 ASAP 式残差模型。
