# 盘点 00 · 全仓库模块地图与最佳用法（总览）

> 盘点日期 2026-10-21。逐模块详表见同目录 01-09。本文件是全仓库的「打通视图」。

## 一句话现状

仓库已形成一条**完整但未闭环**的链路：上游源码 → 训练主线（能续训并保持官方水平）→ 导出 → sim2sim 跨引擎门禁 ✅ → 比赛仿真验收 ✅ → 打包原型 → 真机（未开始）。差的三环：**(a) 超越官方的证据、(b) 生产 C++↔Python 观测契约、(c) 反应式足球技能（火神式实时感应）**。

## 下一步优先级（综合全部盘点的判断）

1. **RESEARCH-INTEGRATION 第 2 步**：生产 observation 契约对照 + getup→walk 切换——这是部署任何自训策略的前置，阻塞面最大。
2. **路线 A P0**：种子 42/123 重复 + 官方两阶段日程 + 急停/静止命令日程实验（每条单因素、走留出种子评估）。
3. **路线 B P2 资产**：GMR 重定向 ACCAD 行走+CMU 踢球 → K1；虚拟感知噪声模型定义。
4. **RLVisionKick 实机定性**（若计划用真机）：决定它是基线、对照还是干扰项。
5. Isaac Lab 迁移**不在关键路径**（集成方案已明确）；相机类感知策略需要时再动。
