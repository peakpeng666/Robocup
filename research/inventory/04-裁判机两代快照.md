# 盘点 04 · 两代裁判机（25game_controller/ + 26game_controller/）

> 盘点日期 2026-10-21。

## 是什么

HSL GameController 的两代快照（2025 赛季 / 2026 赛季）。Git 树里只有 README + LICENSE + config，**完整可执行程序在 Release 资产里**（README 根目录已注明）。

## 关键结构（26 版）

- `config/` 按 2026 新赛制分六组：**small/middle/large × advanced/foundation**（HSL 每组别再分两个子联赛）+ `teams.yaml`。
- 2026 起 SPL/Humanoid 合并为 HSL，裁判机协议与组别配置随之改版——**25 版与 26 版配置不可混用**。

## 协议要点（本仓库已做字节级对照，见 research-inputs 调研）

| 通道 | 格式 |
|---|---|
| GC→机器人 | UDP 3838，`RGme` v20，158 字节 |
| 机器人→GC | UDP 3939，`RGrt` v4，32 字节 |
| 队内通信 | UDP 10000+队号，单包 ≤512B，有消息预算 |
| 监控真值 | `RGTD`，仅评估侧 |

## 怎么用最好

1. 六机比赛仿真/真机比赛**必须用 26 版**（对应 HSL 2026 规则）；25 版仅作历史对照。
2. 多机器人独立身份联调时按此前调研的架构：macvlan/ipvlan 或独立 netns，每机独立 IP + SDK 端点，注意 DDS 域隔离。
3. 真实 GC 联调跑 1× 墙钟；加速训练用仿真裁判/仿真时钟，别混。
4. 运动判定要处理 stopped/处罚/陈旧数据/哨声事件，不能只看 PLAYING。
