# 盘点 07 · 比赛仿真验证工作区（bhuman/local-k1-validation-20261019/）

> 盘点日期 2026-10-21。

## 是什么

B-Human 比赛程序的**本机可运行副本 + 全套验收脚手架**：在这里跑真实比赛栈（感知/行为/步态全链路），产出机器可读的比赛证据。原始 BHumanCodeRelease 保持干净，所有本地修改都圈在本工作区。

## 结构

| 路径 | 内容 |
|---|---|
| `bhuman-local/` | BHumanCodeRelease 克隆（分支 `local-k1-sim`，1 个本地提交 + 12 文件修改 + 6 组新 K1 场景：Audit{Fast,Normal,Oracle}、BHumanLocal{Gait,Match}） |
| `scripts/` | 26 个脚本：比赛运行（run-bhuman-k1.py）、GPU 视觉准备/校验、速度基准（benchmark-bhuman.py）、长赛分析、起身矩阵/长测/审计、证据汇总 |
| `reviews/` | 验收报告（部署报告、速度与长测报告、起身长测报告等） |
| `standup-audit/`、`runs/` | 审计与运行产物 |
| `STATUS*.md`、`SYNC-*` | 状态与同步核验记录 |
| `runtime/` | **本机运行时（不入归档）** |

## 已验收证据（STATUS.md）

- **六机正常视觉比赛 660s 连续仿真，549.5s 墙钟（1.201× 实时）**，5:5、0 跌倒、0 非有限值、六台稳定站立收尾；6600 帧录像复核通过（Release + GPU 视觉，运控为原版 CPU 策略）。
- 单机步态 30s、六机 120s（1:1、44 条触球、一台跌倒后自行恢复）均通过。
- 起身环境 v3：28 env × 前后各 7 姿态 × 最长 120s；安静/公开扰动参考完成率 ~99.61%；最大物理超调 0.021554 rad。
- 边界：持续站立严格站稳 ~96.3-96.5%（有抖动/位移）；**持续施力加强组 55/531 跌倒**；侧躺恢复/起身-行走交接/快速起身/真机未验收。

## 怎么用最好

1. **这是「比赛层验收」的唯一通道**：任何自训策略要进比赛，先在这里做 SimRobot 场景验收（Audit* 三档场景正好对应 感知Oracle/正常/快速 三种预算），再上 GPU 视觉六机长测。
2. `BHumanLocalGait/Match` 场景可作为**新步态的比赛对照舞台**：同一比分/触球/跌倒统计下比官方步态 vs 候选步态。
3. GPU 视觉管线（prepare/validate-gpu-vision.py）证明了视觉可 GPU 加速——为将来「视觉 25Hz + 策略 50Hz」的火神式闭环预留了算力路径。
4. 起身审计脚手架（run-standup-*）可直接复用到「起身→行走交接」这一未验收项。
