# 06 · 落地路线建议（与本仓库现状对齐）

> 前提：本仓库 2026-10-20 诊断结论——有界续训能保持官方水平但未超越；急停收敛 9/24（官方 11/24）、站立抖动、>30% 分段退化项。以下路线按「先本体感、再感知闭环」排序，每步都有可证伪的验收。

## 路线 A：纯本体感步态强化（短期，现有栈）

目标：速度/急停/抗扰全面 ≥ 官方，且有统计证据。

1. **命令日程改造**：把零命令驻留、急停段、反转段按比赛分布加权进命令采样；零命令改用比赛式「站立模式」而非固定 1.5Hz 步态。
2. **奖励微调**：settle-time 奖励（急停收敛直接对应）；站立抖动加动作率/足端微滑惩罚。
3. **扰动课程**：对照公开 actor 的 stress 分组（当前 531 个持续施力事件 55 次跌倒），分级推力课程 + 留出组。
4. **估计器对照组**：RMA/双历史/CENet 三选一，与现状（10 帧历史直接进 actor）做 A/B；单因素，别叠加。
5. **参考约束退火**：现配方参考惩罚权重 1 固定；开单因素分支做退火日程，验证能否在不退化前提下放开探索。

验收：沿用三留出评估种子（2027/2028/2029）+ 新增扰动分组；急停收敛目标 ≥ 18/24 且无单项 >15% 退化；PhysX 非逐位确定，微差不作结论。

## 路线 B：火神式感知闭环（中期，核心目标）

T1→K1 迁移清单（来自本仓库此前调研，仍然有效）：

1. K1 质量/惯量/足底/驱动限位建模（booster_assets URDF/MJCF 为准）。
2. 参考动作重定向：ACCAD 全向行走 + CMU#10/自采踢球 → **GMR → K1**，验证支撑足接触。
3. 观测/动作重定义：K1 22 DoF；官方行走是 12 腿关节偏置+1 步频偏置；火神 T1 是头/腰/腿 15 维。决定 K1 版动作空间（建议保留官方行走接口，新增头 2 维用于主动感知）。
4. 虚拟感知系统：紧凑结构化观测（球位置、球门中心、球门法向，机器人系）+ 视场/遮挡/漏检/噪声/延迟（116±18ms 起步标定）——**不要先上原始像素**。
5. encoder-decoder：历史压缩 + 特权状态重建辅助损失；多 critic；对称损失；AMP（tanh Wasserstein + 梯度惩罚）。
6. 训练：单阶段 PPO；4096 env 起步，沿用本仓库 KL/恢复基建。
7. 切换连续性：普通行走 ↔ 反应技能切换时历史/相位/关节请求连续（本仓库列为未验收项）。

上层仍用 B-Human 行为树，反应策略在「主攻手+近球+空间合适」时激活（火神同款架构），保证不退化现有比赛能力。

## 路线 C：teacher-student 蒸馏对照（与 B 并行的小成本实验）

复现 UT Austin 四阶段（特权 teacher → DAgger 蒸馏 → 在线约束 RL 适配）：代码 https://github.com/Daffan/humanoid-soccer 。价值在于**与路线 B 互为对照**：蒸馏派 vs 单阶段端到端派，哪个在 K1 上更快收敛、更稳。

## 路线 D：real-to-sim 数据管线（真机阶段前置）

1. 按 Booster Lab/ASAP 思路：真机采集 → 反标仿真参数（延迟、PD 响应、摩擦）→ delta action 残差模型。
2. 本仓库 sim2sim（MuJoCo 3.8）通道已验收，先把「Gym 导出 → MuJoCo 回放」作为每次训练的固定门禁。
3. 固件/SDK 兼容性：B-Human 文档测 1.7.1 镜像；booster_deploy README 要求 ≥1.7.2——真机阶段前必须实测核实（本仓库调研已记录的冲突点）。

## 验收协议（沿用并加固）

- 评估种子 2027/2028/2029 留出；训练种子与评估种子分离；PhysX 微差不作显著性结论。
- 指标：vx/vy/wz RMSE（分段 settled）、急停收敛 x/24、跌倒率（真实 done/time_outs 计数）、触球时间（1.5m 多朝向）、技能成功率、切换连续性。
- 统计口径：300 次零失败 ⇒ 单侧 95% 失败率上界 ≈1%；成功视频不作为证据。
- 所有 run 保留源码快照/指纹/配置/指标；官方 actor 永为同条件对照。

## 风险

- 火神公开资产是 T1 版；K1 无腰（官方行走不含腰部自由度），主动感知只能靠头 2 维 + 全身朝向——观测设计要重新论证。
- 视觉闭环的真机算力：K1 机载 Orin NX/AGX 视版本 48-200 TOPS，策略 50Hz + 视觉 25Hz 可行，但要预留 B-Human 比赛栈的算力份额。
- Isaac Gym 已停更：新栈迁移（Isaac Lab）时机建议在 P3 之后，避免算法/仿真器双变量混淆。
